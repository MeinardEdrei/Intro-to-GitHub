# Git & GitHub notes

Just some quick notes for Task 1 of the assignment.

## Git vs GitHub
Git is the actual version control tool, it runs on your own computer and keeps track of every
change you make to your files. GitHub is just a website that hosts your Git repos online so
other people can see them, work on them with you, open issues, etc. Basically Git = the tool,
GitHub = where you park your Git projects and collaborate.

## Why version control matters
Without it you end up with stuff like "final_v2_reallyfinal.docx". Version control keeps a full
history of every change, lets multiple people work on the same project without stepping on each
other's changes, and you can always go back to an older version if something breaks.

## Terms I need to know
- **Repository (repo)** - the folder Git is tracking, has all your files + their history
- **Commit** - basically a save point, a snapshot of your changes with a message attached
- **Branch** - a separate copy of the code you can mess with without touching the main version
- **Pull request** - asking to merge your branch's changes into another branch, usually gets reviewed first
- **Merge** - actually combining the changes from one branch into another
